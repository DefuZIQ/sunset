# Автоматическое тестирование

## Полный запуск

Из корня проекта:

```powershell
.\scripts\test-all.ps1
```

С браузерными E2E в desktop/mobile Chromium:

```powershell
.\scripts\test-all.ps1 -WithE2E
```

С проверкой уже развёрнутого сайта:

```powershell
.\scripts\test-all.ps1 -WithSmoke -BaseUrl http://192.168.1.186
```

## Покрытые сценарии

- Gateway: публичный путь без JWT, отказ защищённому запросу без JWT.
- Auth: регистрация и BCrypt, дубликат email, успешный/ошибочный вход, правила нового пароля.
- Auth + PostgreSQL 16/Testcontainers: миграции на пустой БД, регистрация, роль клиента, JWT, сохранение профиля и смена пароля. Новые тесты компилируются; запуск с PostgreSQL ожидает доступного Docker.
- Order: пустая корзина, неизвестный промокод, недопустимый статус, нулевая корректировка бонусов.
- Order + PostgreSQL 16/Testcontainers: Liquibase с чистой БД, оформление и подтверждение заказа, отложенное начисление бонусов, полная компенсация при отмене, идемпотентный повтор, резервирование остатка и транзакционный откат при ошибке оплаты.
- Product: обязательность UUID, 404 неизвестного товара, успешная выдача карточки.
- Product + PostgreSQL 16/Testcontainers: все миграции и начальный каталог, дерево категорий, варианты товара и рейтинг из сохранённых отзывов. Новые тесты компилируются; запуск с PostgreSQL ожидает доступного Docker.
- Notification: ограничение размера страницы, счётчик, чтение владельцем и запрет чужому пользователю.
- Newsletter: email-валидация, нормализация/создание, безопасная отписка отсутствующей записи.
- Frontend: запуск приложения, навигация, защита admin-маршрута для гостя, варианты корзины, количество, удаление, очистка и восстановление из `localStorage`.
- Playwright E2E: каталог и фильтрация, поиск, выбор размера и корзина, защита admin-маршрута; desktop и mobile Chromium.
- Smoke: web, непустой каталог, минимум 100 товаров, категории, карточка товара, акции и HTTP 401 для гостя.

## Что ещё необходимо для production-grade покрытия

- Запустить новые PostgreSQL-тесты Auth и Product Service в окружении с Docker; дополнить их конкурентной проверкой последнего остатка.
- HTTP E2E полного клиентского пути: регистрация → корзина → доставка/самовывоз → заказ → административное подтверждение → отмена.
- Контрактные тесты Gateway и downstream-сервисов.
- Проверки параллельного оформления последнего остатка и идемпотентности отмены.
- Тесты внешних интеграций: Ollama, геокодер, будущие платежи и email.
