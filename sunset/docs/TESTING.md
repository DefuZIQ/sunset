# Автоматическое тестирование

## Полный запуск

Из корня проекта:

```powershell
.\scripts\test-all.ps1
```

С проверкой уже развёрнутого сайта:

```powershell
.\scripts\test-all.ps1 -WithSmoke -BaseUrl http://192.168.1.186
```

## Покрытые сценарии

- Gateway: публичный путь без JWT, отказ защищённому запросу без JWT.
- Auth: регистрация и BCrypt, дубликат email, успешный/ошибочный вход, правила нового пароля.
- Order: пустая корзина, неизвестный промокод, недопустимый статус, нулевая корректировка бонусов.
- Product: обязательность UUID, 404 неизвестного товара, успешная выдача карточки.
- Notification: ограничение размера страницы, счётчик, чтение владельцем и запрет чужому пользователю.
- Newsletter: email-валидация, нормализация/создание, безопасная отписка отсутствующей записи.
- Frontend: запуск приложения, навигация, защита admin-маршрута для гостя, варианты корзины, количество, удаление, очистка и восстановление из `localStorage`.
- Smoke: web, непустой каталог, минимум 100 товаров, категории, карточка товара, акции и HTTP 401 для гостя.

## Что ещё необходимо для production-grade покрытия

- Интеграционные тесты PostgreSQL через Testcontainers со всеми Liquibase-миграциями.
- E2E Playwright: регистрация → корзина → доставка/самовывоз → заказ → отмена; административное подтверждение и бонусы.
- Контрактные тесты Gateway и downstream-сервисов.
- Проверки параллельного оформления последнего остатка и идемпотентности отмены.
- Тесты внешних интеграций: Ollama, геокодер, будущие платежи и email.
