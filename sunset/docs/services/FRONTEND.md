# Сервис Frontend

## Ответственность

React SPA реализует клиентскую витрину и личный кабинет. Административный интерфейс имеет отдельный HTML-вход и оболочку по `/admin/`; пока он собирается в том же frontend-проекте и раздаётся тем же веб-сервером. Caddy проксирует API-запросы к Gateway. Это состояние исходников от 16 октября 2026; установка на production ожидает проверки миграции IAM.

## Маршруты

| Маршрут | Экран |
|---|---|
| `#/` | Главная |
| `#/catalog` | Каталог и фильтры |
| `#/catalog/product/:id` | Карточка товара |
| `#/newproducts` | Новинки |
| `#/about`, `#/contacts`, `#/promotions` | Информационные страницы |
| `#/search` | Результаты поиска |
| `#/login`, `#/register` | Вход и регистрация |
| `#/profile/*` | Кабинет, заказы, адреса, избранное, бонусы, настройки, уведомления |
| `#/profile/basket` | Корзина и оформление |
| `/admin/` | Отдельная панель управления; вход по отдельному сеансу вкладки |
| `#/admin` | Переход со старого адреса на `/admin/` |

## Состояние

- `StoreContext` — загрузка каталога и доступ к товарам.
- `CartContext` — варианты товаров и количество, сохранение в `localStorage`.
- `FavoritesContext` — избранное, сохранение в `localStorage`.
- `App` — покупательская сессия, повторная загрузка профиля и маршрутизация витрины.
- `AdminApp` — отдельная проверка IAM-доступа и административный токен в `sessionStorage`.

## Внешние зависимости

Frontend обращается к относительным путям API, поэтому одинаковая сборка работает за Caddy без жёстко заданного домена. OpenStreetMap используется во встроенной карте. Web Speech API применяется для голосового взаимодействия с помощником, если его поддерживает браузер.

Android-клиент в `android-app/` открывает покупательскую витрину с `https://t3ch.pro/` в защищённом WebView, поэтому те же относительные API-маршруты и аккаунты работают без второго backend. Голосовая кнопка при User-Agent `SunsetAndroidApp/` вызывает системный Android-распознаватель через схему `sunset://voice`; результат возвращается событием `sunset-native-voice-result`. Обычные браузеры продолжают использовать Web Speech API. Сборка и ограничения описаны в [Android README](../../android-app/README.md).

## Сборка

```bash
cd frontend
npm ci
npm run build
```

Сборка выполняется Vite, тесты — Vitest. Результат находится в `frontend/dist` и копируется в образ Caddy.

## Ограничения

- Переход на Vite завершён; следующий этап модернизации — TypeScript, React Query и feature-модули.
- Компоненты `Profile`, `Cart` и `Admin` слишком велики и объединяют UI, запросы и бизнес-правила.
- Адреса и способы оплаты пока не являются полноценными серверными сущностями.
- Нет единой библиотеки форм, схемной валидации и query/cache-слоя.
