# Сервис авторизации и профиля

## Ответственность

Регистрация, вход, получение и обновление профиля, смена пароля, хеширование паролей и выпуск JWT. Работает на порту 8081.

## API

- `POST /auth/register` — создание клиента.
- `POST /auth/login` — проверка учётных данных и выдача JWT.
- `GET /auth/profile` — актуальный профиль текущего пользователя.
- `PUT /auth/profile` — изменение имени, контактов, дня рождения и аватара.
- `PUT /auth/profile/password` — смена пароля после проверки текущего.

## Данные

Основная сущность — `User`. Миграции создают пользователей и роли, затем добавляют телефон и роль верхнего уровня. `UserRepository` обеспечивает поиск по email и UUID.

## Безопасность

Spring Security защищает профильные endpoints. `JwtUtil` выпускает и разбирает токены, `JwtFilter` создаёт контекст аутентификации. Пароли должны храниться только как BCrypt-хеши.

## Ограничения

- Нет подтверждения email/телефона, восстановления пароля и управления активными сессиями.
- Аватар передаётся как поле профиля; отсутствует отдельное объектное хранилище и обработка изображения.
- В `application.properties` присутствуют реквизиты и секреты по умолчанию — их необходимо удалить из репозитория и заменить окружением.
