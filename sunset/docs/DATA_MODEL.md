# Модель данных

## Пользователи

- `users` — идентификатор, email, хеш пароля, имя, фамилия, телефон, день рождения, аватар, роль.
- `roles`, `user_roles` — ранняя ролевая модель; сейчас параллельно существует поле `users.role`.

## Каталог

- `products` — название, описание, цена, пол, дата создания.
- `images` — URL изображения.
- `product_images` — изображения товара и тип ракурса/привязка к цвету.
- `categories` — дерево через `parent_id`.
- `product_categories` — категории товара.
- `colors`, `product_colors` — справочник и доступные цвета.
- `sizes` — имя, подпись, тип вещи, пол, регион, описание, порядок.
- `product_stock` — остаток комбинации товар/размер/цвет.
- `product_reviews` — рейтинг, текст, автор и дата отзыва.

## Заказы

- `orders` — клиент, контакты, адрес, статус, суммы, бонусы, промокод, номер и даты.
- `order_items` — снимок товара, варианта, количества и цены.
- `payments` — будущие платёжные операции.
- `deliveries` — данные доставки.
- `stores` — магазины и пункты самовывоза.

## Лояльность

- `loyalty_accounts` — баланс клиента.
- `loyalty_transactions` — неизменяемый журнал начислений, списаний и компенсаций.
- `promotions` — код, описание, скидка, множитель бонусов, минимальная сумма и период активности.

## Коммуникации

- `notifications` — сообщения пользователю и признак прочтения.
- `newsletter_subscriptions` — email, пользователь, активность и время обновления.

## Целевые инварианты

- Остаток не может быть отрицательным.
- Цена и денежные итоги не могут быть отрицательными.
- Email уникален без учёта регистра.
- Баланс равен сумме подтверждённых транзакций или регулярно сверяется с ней.
- Отмена заказа создаёт ровно одну компенсацию каждой применённой бонусной операции.
- Номер заказа уникален и неизменяем.
- Категория не может быть собственным предком.
- Один отзыв пользователя на товар допускается только после покупки либо по явно выбранному бизнес-правилу.

## Рекомендуемое владение

| Сервис | Собственные таблицы |
|---|---|
| Auth | users, roles, user_roles |
| Product | products, images, categories, colors, sizes, связи, stock, reviews |
| Order | orders, order_items, payments, deliveries, stores, loyalty, promotions |
| Notification | notifications, newsletter_subscriptions |

Другие сервисы должны получать данные через API или события, а не читать чужие таблицы напрямую.
