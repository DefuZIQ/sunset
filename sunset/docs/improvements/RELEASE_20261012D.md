# Веб-релиз: названия категорий без повторения пола

Дата: 12 октября 2026. Код: `389942c` в ветке `codex/commerce-platform-v1`.

В каталоге, карточках товара и админке отображается «Верхняя одежда → Пальто» вместо «Мужская верхняя одежда → Мужские пальто». Пол остаётся отдельным разделом или меткой. Когда в фильтре выбран раздел «Женщинам» или «Мужчинам», его корневой узел не повторяется в дереве. Внутренние имена категорий в БД, API и URL не менялись: существующие товары, ссылки и фильтры остаются совместимыми.

Проверки: 64 unit-теста, TypeScript, production-сборка, 105 браузерных тестов (11 условно пропущены), [CI](https://github.com/DefuZIQ/sunset/actions/runs/38209883388) и [Quality gate](https://github.com/DefuZIQ/sunset/actions/runs/38209883848) прошли. После публикации целевой браузерный сценарий категорий прошёл на desktop и mobile; live smoke главной, каталога, карточки товара и контактов тоже прошёл.

Локальный сайт `192.168.1.186` обновлён через `scripts/deploy-web.sh`; прежний образ доступен как `sunset-web:rollback`, исходники сохранены в `/home/defuziq/backups/category-ui-pre-20261012d.tar.gz`. Публичный фронтенд на VDS опубликован в `/srv/sunset/releases/categories-clean-20261012`; `/srv/sunset/current` переключён на него. Прежняя директория `/srv/sunset/releases/filter-design-20261011` сохранена. При первом переключении каталог нового релиза имел права `700`, поэтому Nginx кратко вернул 403; права директорий исправлены на `755`, файлов на `644`, после чего публичные проверки прошли.

Для отката публичного фронтенда создать ссылку на `/srv/sunset/releases/filter-design-20261011` в `/srv/sunset/current.next`, атомарно заменить ею `/srv/sunset/current` через `mv -Tf`, затем проверить `https://t3ch.pro/`. Для локального фронтенда выполнить `sudo docker image tag sunset-web:rollback sunset-web:latest`, пересоздать только `web` через Compose без сборки и проверить главную страницу.
