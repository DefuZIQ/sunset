## Изменение

Gateway обновлён с Spring Boot `3.1.4` / Spring Cloud `2022.0.4` до Boot `3.5.16` / Cloud `2025.0.3`. Маршруты и CORS переведены на ключи `spring.cloud.gateway.server.webflux.*`; HTTP-контрактные тесты тоже используют новые ключи. Другие сервисы в этом релизе не пересобирались и не переключались; схема БД не менялась.

В новом JAR: `spring-webflux 6.2.19`, `spring-security-web 6.5.11`, `netty-handler 4.1.135.Final`, `bcprov-jdk18on 1.80.2`. Отчётный OSV-аудит после изменения показал 151 срабатывание, включая 14 Critical, против 236/16 до обновления Gateway. Это не означает, что все оставшиеся результаты применимы к запущенному коду; они требуют дальнейшего разбора и обновления остальных сервисов.
