# Релиз IAM и отдельной админки — 16 октября 2026

## Что опубликовано

- Административный frontend — отдельная точка входа `https://t3ch.pro/admin/`, со своим входом и токеном в `sessionStorage`. Магазин и админка пока используют один origin и общий backend; это не полная инфраструктурная изоляция.
- Auth Service: таблицы `iam_user_permissions`, `iam_access_audit`, API проверки и назначения прав. `ADMIN` имеет все права; сотруднику выдаются только явно назначенные разрешения.
- Product и Order Service проверяют разрешения на административных действиях. Публичный магазин и клиентские маршруты продолжают работать.

## Откат

На VM вернуть прежние образы по одному, начиная с Order и Product, затем Auth: присвоить соответствующий `rollback-iam-20261016` тегу `latest` и пересоздать только этот сервис через `docker compose -f docker-compose.prod.yml up -d --no-deps --no-build --wait --force-recreate SERVICE`. Прежний web-образ доступен как `sunset-web:rollback-iam-20261016`. Миграция IAM только добавляет таблицы; при откате приложений их можно оставить без удаления клиентских данных.

На VDS прежний frontend — `/srv/sunset/releases/filter-a11y-20261015`, прежний Nginx-конфиг — `/etc/nginx/sites-available/sunset.pre-iam-20261016`. Переключить `/srv/sunset/current` обратно на предыдущий релиз, восстановить конфиг, выполнить `nginx -t` и только после успешной проверки — `systemctl reload nginx`. Не удалять текущий релиз или резервную копию до подтверждённого восстановления.
