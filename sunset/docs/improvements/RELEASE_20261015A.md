# Доступность мобильных фильтров каталога

Дата: 15 октября 2026. Код: `8829ceb` в ветке `codex/commerce-platform-v1`.

Закрытая панель фильтров на экранах до 900 px теперь исключена из порядка клавиатурной навигации. Открытая панель обозначена как модальное окно: фокус переходит на кнопку закрытия, Tab и Shift+Tab остаются внутри неё, Escape закрывает окно и возвращает фокус на кнопку «Фильтры». Прокрутка страницы на время открытия блокируется. На широком экране фильтры остаются обычной доступной боковой панелью. Также стабилизирован браузерный тест телефона в оформлении заказа: он ждёт загрузки выбранного магазина перед проверкой.

Проверки: 64 unit-теста, TypeScript, production-сборка; 109 Playwright-тестов прошли, 11 условно пропущены. Первый общий прогон встретил тайм-аут при закрытии одного мобильного теста, повторный выявил гонку в тесте оформления; после исправления ожидания полный прогон с четырьмя браузерами прошёл. Отдельный тест фильтров прошёл на desktop и mobile.

Локальный веб-образ опубликован на `192.168.1.186`, предыдущий образ доступен как `sunset-web:rollback-filter-a11y-20261015`; прежний исходник сохранён в `/home/defuziq/backups/filter-a11y-source-pre-20261015.tar.gz`. Публичная сборка опубликована в `/srv/sunset/releases/filter-a11y-20261015`, предыдущая — `/srv/sunset/releases/review-comments-20261012`. На обоих адресах прошли desktop/mobile live smoke и отдельная браузерная проверка открытия фильтров, Escape и возврата фокуса.

Для отката локального сайта вернуть rollback-образ под тег `sunset-web:latest`, пересоздать только `web` через Compose и проверить страницу каталога. Для публичного сайта атомарно переключить `/srv/sunset/current` на прежнюю директорию релиза, затем проверить `https://t3ch.pro/`.
