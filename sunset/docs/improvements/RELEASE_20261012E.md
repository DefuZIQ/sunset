# Комментарии к отзывам

Дата: 12 октября 2026. Ветка `codex/commerce-platform-v1`, код `b134cdf` и исправление `78e7735`.

В карточке товара у каждого отзыва появился разворачиваемый блок комментариев. Читать их можно без входа, писать — после авторизации. Автор может удалить свой комментарий с подтверждением; администратор может удалить любой. Список загружается порциями по 20, счётчик виден рядом с отзывом. Комментарии к скрытому отзыву не выдаются; при удалении отзыва его комментарии удаляются каскадно.

Добавлены таблица `review_comments` (Liquibase changeset 126), сервис и HTTP API. Контракт OpenAPI и клиентские типы обновлены. Валидация текста: 2–1000 символов, смещения списка: 0–10000. Имя автора берётся из профиля на момент публикации.

Проверки: 14 backend-тестов, включая интеграционные на PostgreSQL 16 и HTTP-тест привязки `offset`; OpenAPI — 61 операция; клиентская проверка типов, сборка и два E2E-сценария комментариев (desktop/mobile) прошли. Публичный live smoke на desktop/mobile прошёл. После исправления HTTP-запросы списка комментариев с `offset=0` на `https://t3ch.pro` и `192.168.1.186` вернули корректный ответ.
