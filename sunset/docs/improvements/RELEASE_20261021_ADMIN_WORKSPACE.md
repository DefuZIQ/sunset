# Рабочая панель администратора

Дата: 21 октября 2026.

Отдельная админка использует всю ширину экрана: постоянное левое меню на компьютере и выдвижное меню на телефоне. Разделы остались привязаны к IAM-разрешениям; счётчики новых заказов и заявок на возврат видны в меню. Обзор содержит переходы к задачам, безопасность вынесена в отдельный раздел. Добавлены обновление данных, поиск и фильтр статуса в заказах, поиск клиентов и поиск товаров. При закрытии мобильного меню клавишей Escape фокус возвращается на кнопку открытия.

Изменён только фронтенд. Административные API, полномочия и схема БД не менялись. Существующие действия с заказами, возвратами, товарами, остатками, отзывами, акциями, клиентами и доступом сохранены.

Проверки: `npm run typecheck`, `npm run build`, 74 unit-теста и полный Playwright-набор с четырьмя параллельными исполнителями — 123 passed, 11 skipped. Новый браузерный сценарий проверяет фильтры, мобильное меню, отсутствие горизонтального переполнения и экран безопасности. Первоначальный запуск с десятью исполнителями дал четыре тайм-аута; все четыре прошли отдельно, затем весь набор прошёл с четырьмя исполнителями. Публичный и локальный desktop/mobile live smoke прошли после установки.

Локальный релиз `192.168.1.186`: финальный веб-образ `sunset-web:candidate-admin-workspace-20261021b`, прежний сохранён как `sunset-web:rollback-admin-workspace-20261021b`. Публичный релиз: `/srv/sunset/releases/admin-workspace-20261021b`; предыдущие `/srv/sunset/releases/admin-workspace-20261021` и `/srv/sunset/releases/mfa-qr-20261021` сохранены. Финальная корректировка удерживает уведомление об успешном сохранении при автообновлении данных. Переключение выполнено через сценарии в `deploy/admin-workspace-candidate/` после проверки прав файлов и `nginx -t`.

Откат: на VM пометить `sunset-web:rollback-admin-workspace-20261021b` как `sunset-web:latest` и пересоздать только `web` через Compose без сборки. На VDS атомарно переключить `/srv/sunset/current` обратно на `/srv/sunset/releases/admin-workspace-20261021`. Для полного отката редизайна использовать предыдущий релиз `mfa-qr-20261021`. Затем проверить `/` и `/admin/`.
