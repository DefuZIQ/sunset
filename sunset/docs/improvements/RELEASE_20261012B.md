## Откат

Для каждого сервиса из `auth-service`, `product-service`, `order-service`, `notification-service`, `api-gateway` выполнить в `/home/defuziq/sunset`:

```sh
sudo docker image tag sunset-SERVICE:rollback-20261012b sunset-SERVICE:latest
sudo docker compose -f docker-compose.prod.yml up -d --no-deps --no-build --wait --force-recreate SERVICE
```

Заменить `SERVICE` на конкретное имя и проверить health/публичные маршруты. При откате образов восстановить соответствующие исходники из архива. Новых миграций БД в релизе нет.
