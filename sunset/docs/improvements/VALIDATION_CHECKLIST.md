# Чек-лист проверки улучшений

## Документация

- [ ] Все относительные Markdown-ссылки разрешаются.
- [ ] Аудит содержит безопасность, заказы, каталог, UX, архитектуру, эксплуатацию и тестирование.
- [ ] P0-спецификация содержит объём, исключения, критерии, выкладку и откат.
- [ ] Реализованный код не выходит за утверждённый P0-объём.

## Безопасность

- [ ] Клиентский `user-id` удаляется на публичных запросах без JWT.
- [ ] Клиентский `user-id` заменяется subject валидного JWT.
- [ ] Уведомления не принимают `userId` из query/body.
- [ ] Подписка не принимает доверенное решение по `userId` из body.
- [ ] Status/unsubscribe нельзя вызвать без JWT.
- [ ] В отслеживаемых конфигурациях отсутствуют известные рабочие пароли и JWT secret.

## Качество

- [ ] Backend unit/integration tests проходят.
- [ ] Frontend tests проходят.
- [ ] Frontend production build проходит.
- [ ] Production smoke checks проходят после выкладки.
- [ ] `git diff --check` не сообщает об ошибках пробелов.

## Выкладка

- [ ] Ветка имеет префикс `codex/` и отдельна от `master`.
- [ ] Коммиты отправлены в GitHub.
- [ ] До установки создан backup PostgreSQL ненулевого размера.
- [ ] Все контейнеры имеют ожидаемый статус.
- [ ] Главная страница, каталог и health отвечают после установки.
