## Откат

При проблеме конкретного backend-сервиса на сервере: `sudo docker image tag sunset-<service>:rollback-20261011a sunset-<service>:latest`, затем из `/home/defuziq/sunset` выполнить `sudo docker compose -f docker-compose.prod.yml up -d --no-deps --no-build --wait --force-recreate <service>`. После этого проверить health и сайт. Для отката всех сервисов повторить по одному в обратном порядке: Gateway, Order, Product, Auth, Notification. Веб-образ возвращается командами `sudo docker image tag sunset-web:rollback-20261011a sunset-web:latest` и `sudo docker compose -f docker-compose.prod.yml up -d --no-deps --no-build --wait --force-recreate web`. Миграции БД не откатываются этими действиями: добавленные таблицы и сужение `colors.hex_code` уже применены; старый код следует запускать только после отдельной проверки совместимости. Исходники до релиза сохранены по указанным путям, резервная копия БД — отдельно.

Реальные платёжный и логистический провайдеры, внешняя доставка тревог, серверный поисковый индекс и разделение общей БД остаются незавершёнными этапами плана.
