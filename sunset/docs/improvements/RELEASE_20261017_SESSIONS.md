# Серверные сессии IAM — 17 октября 2026

## Выпущено

- Auth Service регистрирует JWT с уникальным `jti` в `auth_sessions`. Административные и рабочие токены действуют 15 минут, клиентские — 24 часа. `POST /auth/logout` отзывает текущий сеанс, смена пароля — все сеансы пользователя.
- Gateway проверяет каждый предъявленный токен через Auth Service. Отозванный токен получает `401`; при недоступности проверки возвращается `503` без доступа к защищённому маршруту.
- Админка и магазин при выходе обращаются к серверу; после смены пароля клиент входит заново. Уже истёкший токен не мешает локальному выходу.
- Миграция Liquibase V6 только добавляет таблицу `auth_sessions`. Клиентские токены старого формата действуют до исходного истечения; старые токены `ADMIN`/`STAFF` требуют повторного входа.

## Откат

При необходимости сначала вернуть прежний frontend (VDS-симлинк `current` на `iam-20261016`, VM web-образ с `rollback-sessions-20261017`), затем прежний Gateway и только после него Auth. Иначе новый Gateway не сможет проверить сессии на старом Auth. Каждый сервис пересоздавать отдельно и проверять health/API. Миграция V6 добавочная; таблицу при откате не удалять. Бэкап хранить для восстановления данных, а не применять автоматически при обычном откате кода.
