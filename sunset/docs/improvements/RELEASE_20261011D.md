## Откат

Для каждого сервиса из `auth-service`, `product-service`, `order-service`, `notification-service` выполнить в `/home/defuziq/sunset`:

```sh
sudo docker image tag sunset-SERVICE:rollback-20261011d sunset-SERVICE:latest
sudo docker compose -f docker-compose.prod.yml up -d --no-deps --no-build --wait --force-recreate SERVICE
```

Заменить `SERVICE` на конкретное имя и проверить health/публичные маршруты. При откате к прежним образам восстановить POM-файлы из указанного архива. Миграций БД в релизе нет.
