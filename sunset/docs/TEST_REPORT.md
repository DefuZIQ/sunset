- Notification Service не имел тестовой зависимости; добавлен `spring-boot-starter-test`.
- Из CartContext удалены отладочные `console.log`.
- Smoke-сценарий сделан совместимым с Windows PowerShell 5.1 и корректно декодирует бинарное представление JSON-ответа Actuator.

## Найденные риски, не устранённые автоматически

1. Миграция с `react-scripts` на Vite завершена. `npm audit` для полного дерева и production-зависимостей сообщает 0 уязвимостей.
2. Старые smoke-тесты Spring-контекста всё ещё используют H2; критический SQL заказов теперь отдельно проверяется на PostgreSQL 16 через Testcontainers.
3. Единый HTTP E2E через Gateway, реальные Auth/Product/Order Service и временную PostgreSQL реализован для самовывоза. Браузерный сценарий доставки и сохранённого адреса использует детерминированные API-ответы; реальная интеграция геокодера и платёжного webhook ещё не проверена.
4. Браузерный E2E-контур покрывает каталог, фильтры, поиск, выбор размера, корзину, оформление доставки и самовывоза, телефон и защиту админки; он использует детерминированные API-ответы.
5. Smoke-набор намеренно не создаёт пользователей и заказы на production-сервере, поэтому остаётся безопасным и не меняет бизнес-данные.
