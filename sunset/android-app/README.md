# SUNSET для Android

Это первый Android-клиент покупательского магазина. Он открывает существующий мобильный UI `https://t3ch.pro/` внутри защищённого WebView: те же товары, аккаунт, корзина и API, без отдельной синхронизации данных. Административный сайт остаётся отдельным и открывается во внешнем браузере. Приложению нужен интернет; офлайн-каталог пока не реализован.

## Возможности

- Отдельная иконка, заставка, системная кнопка «Назад», индикатор загрузки и экран повторной попытки при потере связи.
- Сеанс покупателя сохраняется между запусками в приватном хранилище приложения.
- Фотографии для отзывов и аватара выбираются через системный Android-пикер. Приложение принимает только `content://` URI с MIME-типом `image/*`; доступ к файлам устройства целиком не запрашивается.
- Кнопка голосового ввода помощника вызывает системное распознавание речи на русском и возвращает текст на страницу. Нужен установленный на устройстве обработчик распознавания речи.
- Только `https://t3ch.pro/` загружается внутри приложения. Другие HTTPS-ссылки, телефон, почта и карты открываются внешним приложением. HTTP и неизвестные схемы блокируются. Доступ WebView к файлам, смешанному HTTP-контенту, камере и микрофону страницы запрещён.

## Сборка

Установить Android Studio или Android SDK Command-line Tools, затем SDK Platform 36 и Build Tools 36.0.0; **самостоятельно принять** лицензии Android SDK согласно условиям Google. Проект использует Android Gradle Plugin 9.4.0, Gradle 9.6.1 и JDK 17 или новее. Gradle Wrapper JAR проверен по официальному SHA-256 `497c8c2a7e5031f6aa847f88104aa80a93532ec32ee17bdb8d1d2f67a194a9c7`.

```sh
cd sunset/android-app
./gradlew assembleDebug
```

На Windows: `gradlew.bat assembleDebug`. Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для установки: `adb install -r app/build/outputs/apk/debug/app-debug.apk` или открыть APK на Android-устройстве. Не устанавливайте отладочный APK как финальный релиз из неизвестного источника без проверки.

После установки Command-line Tools на Windows лицензии можно просмотреть и принять интерактивно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat" "--sdk_root=$env:LOCALAPPDATA\Android\Sdk" --licenses
```

Затем установить `platforms;android-36`, `build-tools;36.0.0` и `platform-tools` через Android Studio SDK Manager или `sdkmanager`. Веб-часть с поддержкой нативного голосового ввода должна быть развёрнута на `t3ch.pro` до проверки этой функции в APK.

Для публикации потребуется собственный защищённый signing key, подписанный release AAB, проверка на реальных Android-устройствах, описание приватности и страницы магазина приложений. Ключ подписи нельзя помещать в Git. Пуш-уведомления, офлайн-режим и нативная оплата в этот первый выпуск не входят.

## Проверка перед выпуском

1. Открыть приложение после установки, проверить главную, каталог, карточку товара и адаптивное нижнее меню.
2. Войти покупателем, закрыть приложение и открыть снова: сеанс должен сохраниться. Проверить корзину и оформление без создания рабочего тестового заказа, если это production.
3. Выбрать фото для нового отзыва или аватара; проверить предпросмотр и отмену выбора.
4. Проверить голосовой ввод помощника на устройстве с русским распознаванием речи.
5. Отключить интернет и убедиться, что появляется экран повтора. Включить сеть и нажать «Повторить».
6. Проверить внешние ссылки, системную кнопку «Назад», поворот экрана и экранную клавиатуру.

Приложение загружает текущий сайт с сервера; обновления веб-интерфейса появляются без обновления APK. Изменения нативной части требуют новой версии APK/AAB.
